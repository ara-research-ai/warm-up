# Ara Warm Up
Daily Warm Up lists with date history and persistent country filters, hosted on Cloudflare Pages. Access requires a Google account ending in `@ara-research.ai`.

This public repository contains code only. Snapshots, generated pages, credentials, and deployment state stay outside the repository in the server's private `~/.local/share/ara-warm-up` directory. T3 Code Automation runs the daily collector at 9 am Malaysia time.
